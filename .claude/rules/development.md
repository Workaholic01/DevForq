# Development Rules

- Read affected code and tests before editing.
- Reuse repository conventions.
- Keep changes limited to the accepted requirement.
- Do not overwrite unrelated uncommitted changes.
- Do not leave commented-out code.
- Avoid unexplained TODO or FIXME comments.
- Do not add dependencies without documenting the need.
- Update documentation when public behaviour changes.
- Inspect the final diff before reporting completion.
